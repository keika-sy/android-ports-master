# 🎮 Android Ports — Master Dashboard

Katalog port game native Android (decompilasi, rekompilasi statik, dan source port) — **866 entri, 702 game unik**.

## 🌐 Dashboard
Buka `index.html` di browser (atau aktifkan GitHub Pages dari branch `main` / root) — dashboard lengkap dengan pencarian, filter platform/sumber/kebutuhan file, statistik, dan grafik distribusi. Datanya tertanam langsung di halaman, tidak butuh server.

## 📊 Data
- `data/ports.csv` — tabel lengkap (GAME, PLATFORM, PROJECT, URL, NEEDS GAME FILES?, CATATAN, SUMBER)
- `data/ports.json` — format JSON untuk dipakai ulang

## 📚 Sumber data
1. Sheet komunitas "Android Ports - Game Files" (di-pin di r/AndroidNativePorts) — 546 entri

## ⚠️ Catatan
Semua port di daftar ini adalah engine/APK hasil karya komunitas. **File game (ROM/disc/file PC) tidak termasuk** — gunakan copy game milikmu sendiri. Status sebagian entri eksperimental/WIP tertulis di kolom CATATAN.
